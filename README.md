# In My Mom's Tummy

A one-button game: bounce a baby around the womb. Press space, click, tap, or any gamepad face button to kick toward where the baby's head points. F toggles fullscreen.

Static site, no build step. Vanilla JS with Pixi.js from a CDN. Deploy the repo root as-is (e.g. Cloudflare Pages with no build command and output directory `/`).
